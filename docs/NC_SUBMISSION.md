# Nature Communications submission

## Code availability: accurate current wording

The repository is public and MIT-licensed. Until a version DOI is registered,
the following text accurately describes the current access route:

```latex
\section*{Code availability}
The code for data generation and preprocessing, solution-space partitioning,
federated training, and reproduction of the reported analyses and figures is
publicly available at \url{https://github.com/NUDTPingLuo/Fed-PDE} under the MIT
License. The repository includes experiment configurations, recorded seed-level
results, numerical checks and instructions for reproducing the analyses.
```

Record the exact submission commit in the submission materials. The conceptual
system schematic is separately authored; it is not generated by the analysis
scripts. Third-party source datasets remain available from their providers, as
described in `data/README.md` and the manuscript's Data availability statement.

## Add after the archive is published

Append this sentence **only after replacing the placeholder with a resolving
version DOI**, and formally cite the software record:

> The version used for this manuscript (v1.0.0) is archived on Zenodo at
> https://doi.org/[VERSION-DOI].

Import the actual BibTeX record from Zenodo rather than inventing a DOI. Check
the five authors, software title, version, publication year and DOI against the
record. Place Code availability after Data availability and before references.

## Policy sources

Checked 26 October 2026:

- [NC reporting and code policy](https://www.nature.com/ncomms/editorial-policies/reporting-standards)
- [NC submission guidance](https://www.nature.com/ncomms/submit/how-to-submit)
- [NC forms and resources](https://www.nature.com/ncomms/submit/resources)
- [Nature code/software documentation guidelines](https://media.nature.com/full/nature-cms/documents/GuidelinesCodePublication.pdf)

NC requires access to central custom code for editorial/peer review and a Code
availability statement. Its policy recommends a DOI-minting repository and an
open-source license. Code Ocean is an optional supported route; this project
uses the GitHub-plus-Zenodo route once the archive is published.
