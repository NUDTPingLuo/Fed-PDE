# Fed-PDE

Solution-space Dirichlet partitioning, FedAvg and SB-CFO for seven controlled
and public PDE-learning tasks.

## Install

Use Python 3.10+ and a PyTorch build compatible with your CPU/CUDA environment.

```bash
python -m pip install -r requirements.txt
```

The manuscript experiments used an NVIDIA RTX 5090, Python 3.10.22,
PyTorch 2.7.1+cu128 and NumPy 1.26.4.

## Run

Run commands from the repository root. Controlled data are generated by the
included solvers; public-data sources and paths are in [data/README.md](data/README.md).

```bash
python main.py --study all --device cuda:0
python real_world_main.py --task all --device cuda:0
python sb_cfo_main.py --task all --device cuda:0
```

Configurations are in `config/`. Add `--dry-run` to inspect a plan or `--smoke`
for a small integration run. Use `--device cpu` for CPU execution.
Results are generated under `results/` and are not tracked in this source-only
branch. Completed matching runs are skipped; controlled/public runners accept
`--force` to overwrite them. For SB-CFO experiments with changed settings or
source/runtime fingerprints, choose a new `--output-dir`.

The cylinder geometry mask uses rows for y and columns for x, matching the
native velocity arrays. To regenerate all cylinder results with this correction:

```bash
python real_world_main.py --task cfd_cylinder --device cuda:0 --force
```

## Analyze and plot

After generating the experiment results and preparing the public datasets:

```bash
python tools/audit_manuscript.py
python plot_training_sample_thumbnails.py
python plot_paper_figures.py
python plot_sb_cfo_figures.py
```

The audit regenerates the final table and source data in `output/reproducibility/`.
Figures are written under `output/pdf/`; add `--previews` for PNG previews.
The plotting code uses within-seed error differences and pointwise 95% Student-t
intervals across five seeds. Tests and standalone mathematical checks:

```bash
python -m unittest discover -s tests
python tools/check_adam_theory.py
python tools/check_notation_geometry.py
```

## Files

- `config/`: experiment configurations
- `operator_tasks/`, `real_world/`, `sb_cfo/`, `util/`: numerical solvers, data loaders and algorithms
- `main.py`, `real_world_main.py`, `sb_cfo_main.py`: training entry points
- `plot_*.py`, `tools/`, `tests/`: analysis, figures and verification
