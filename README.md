# Fed-PDE

Code and recorded results for **Solution-space heterogeneity shapes federated
learning dynamics across partial differential equations**.

The benchmark groups training responses into solution bins, partitions each bin
with a Dirichlet allocation, and compares federated learning against a stratified
IID reference. SB-CFO uses bin-conditioned gradient prototypes to correct local
updates. Tasks include antiderivative, Burgers, diffusion–reaction, Darcy,
shallow water, cylinder flow and CurveFault-B inversion.

## Quick analysis demo (no training or raw-data download)

Use Python 3.12 for the pinned analysis environment below.

```bash
python -m pip install -r requirements-analysis.txt
python tools/audit_manuscript.py --skip-theory
```

This validates the recorded experiments and regenerates the final seven-task
table and source data in `output/reproducibility/`. See
[reproducibility details](docs/REPRODUCIBILITY.md) for expected outputs,
measured runtime, environment details and the distinction from full retraining.

## Install

Use Python 3.10 or later, and run commands from this repository's root:

```bash
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows PowerShell: .venv/Scripts/Activate.ps1
python -m pip install -r requirements.txt
```

Training uses PyTorch; select an installation compatible with your CUDA driver
for GPU runs. The six dependencies in `requirements.txt` also cover analysis
and plotting. No Codex installation or external plotting skill is required.
Dependencies are not a lockfile for the original training environment;
recorded software and hardware metadata are retained with each experiment.

## Run experiments

Inspect the complete plans without training:

```bash
python main.py --study all --dry-run
python real_world_main.py --task all --dry-run
python sb_cfo_main.py --task all --dry-run
```

Generate controlled data and run the three principal tasks and ablations:

```bash
python main.py --study formal --device cuda:0
python main.py --study clients --device cuda:0
python main.py --study viscosity --device cuda:0
python main.py --study optimizer --device cuda:0
```

Controlled data are generated by the included numerical solvers. For public
tasks, first obtain the datasets described in [data/README.md](data/README.md):

```bash
python real_world_main.py --task all --device cuda:0
```

Run the paired FedAvg/SB-CFO comparisons:

```bash
python sb_cfo_main.py --task all --device cuda:0 --output-dir output/retrained_sb_cfo
```

Use `--device cpu` for CPU execution. Add `--smoke` for a small integration run.
Principal experiments use five seeds, 1,000 communication rounds and five local
steps. Settings and public-data paths are in `config/`.

`results/` contains the recorded CSV/JSON results used in the manuscript, not
trained weights or raw public datasets. Benchmark runners skip complete matching
results; to retrain the controlled/public benchmarks, use a separate checkout
without the archived `results/` directory or change the output paths in the
configuration. SB-CFO checks source/runtime fingerprints, so use the separate
output path above when retraining. Preserve the original results for comparison.

## Reproduce figures

The recorded results allow the quantitative plots to be regenerated without
training or downloading public datasets:

```bash
python plot_paper_figures.py
python plot_sb_cfo_figures.py
```

The updated manuscript figures include illustrative training samples. Generate
the controlled samples, then replace the corresponding plots:

```bash
python plot_training_sample_thumbnails.py
python plot_paper_figures.py --only-formal-curves
python plot_paper_figures.py --only-physical-regime
```

The public sample panels additionally require the raw public datasets:

```bash
python plot_paper_figures.py --only-public-curves
```

PDFs and figure source tables are written under `output/`; SB-CFO plots are in
`output/pdf/sb_cfo/`. Add `--previews` to the two main plotting commands for PNG
previews. The conceptual system schematic is a separately authored manuscript
asset and is not generated by these analysis scripts.

## Checks

```bash
python -m unittest discover -s tests
python tools/audit_manuscript.py
python tools/check_notation_geometry.py
```

The audit includes the numerical Adam and allocation-law checks described in
the Supplementary Information. The geometry script runs without manuscript
files; its optional `--manuscript-dir` flag additionally checks LaTeX notation.

Tests cover partitioning, aggregation, schedules, models, dataset loaders,
paired statistics and plotting contracts. GPU-dependent training performance
and full 1,000-round reproducibility are separate from these checks.
